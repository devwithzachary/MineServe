Host dedicated Minecraft servers directly on your Android phone or tablet with zero root permissions required.

Whether you want to play survival with friends over Wi-Fi, host a modded world, or run a community server with plugins and a browser control panel, MineServe gives you full local control in a clean Material Design 3 interface.

WHY CHOOSE MINESERVE?

100% ROOTLESS SANDBOX
Runs in Android user space using native PRoot virtualization. No root access, Magisk, or unlocked bootloaders required. Resumable downloads and local .jar / .tar.gz imports make first-run setup straightforward.

11 SUPPORTED SERVER & PROXY ENGINES
Create any server in a quick 2-step wizard:
- PaperMC: High-performance, low-latency engine with plugin support
- PurpurMC: Feature-packed Paper drop-in with deep customization
- Folia: Regionized multithreading server software by PaperMC
- Fabric: Lightweight, modern modular modding platform
- Minecraft Forge: Classic and modern modding platform (1.1 to 1.21+)
- NeoForge: Community-driven modding platform for modern modpacks
- Vanilla: Official Java server software from Mojang (1.0 to 1.21+)
- Bedrock Cross-Play (Geyser + Floodgate): Let friends on iOS, Android, Xbox, PlayStation, and Switch join your Java server
- Bedrock Dedicated Server (Beta): Official Mojang native Bedrock server
- Velocity & BungeeCord Proxies: Link multiple servers into one network

MULTI-VERSION OPENJDK ISOLATION
MineServe automatically manages isolated Java runtimes:
- OpenJDK 25 & 21 (Minecraft 1.20.5+ & modern releases)
- OpenJDK 17 (Minecraft 1.17 - 1.20.4)
- OpenJDK 8 (Legacy 1.16.5 down to 1.0)

MATERIAL DESIGN 3 & MULTI-USER WEB ADMIN
Customize Dark or Light themes (with optional Material You dynamic colors on Android 12+), or manage your server from any computer browser on port 8080. Create team accounts (Owner, Admin, Moderator, Viewer) with CSV Audit Log export, stream live console logs, upload & extract .zip files, view live CPU/RAM/TPS charts, and upgrade engine builds.

ZERO-CONFIG MULTIPLAYER & OPTIONAL CLOUD
- Automatic UPnP & NAT-PMP router port forwarding for direct WAN play
- Built-in bore.pub and Playit.gg public tunnels (works over 4G/5G and CGNAT without port forwarding)
- Optional MineServe Cloud add-on (6-digit email code sign-in) for custom *.play.mineserve.app addresses, remote Web Admin access, and encrypted Cloudflare R2 backups

MODRINTH BROWSER & SMART .MRPACK MODPACKS
Search thousands of plugins and mods from Modrinth with 1-tap install, import Modrinth .mrpack modpacks or server .zip archives with automatic client-only mod filtering, or upload custom .jar files.

WORLD, MAP & BACKUP TOOLS
- Import/export .zip and .mcworld saves and reset Nether or End dimensions
- Pre-generate spawn chunks, inspect .mca region files, and prune uninhabited chunks
- Built-in 2D Squaremap live web map viewer
- 1-tap local zip backups with sync to Nextcloud, WebDAV, Android SAF folders, or MineServe Cloud

AUTOMATION, WIDGETS & SAFEGUARDS
- Idle Auto-Shutdown and Auto-Wake on player ping
- Cron-scheduled backups, restarts, and broadcasts
- Low-Battery and Thermal Auto-Stop safeguards
- Home Screen Widget and Quick Settings Tile for 1-tap control
- Native Discord webhook notifications and Crash Log Analyzer
