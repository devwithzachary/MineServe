MineServe is a free, GPL-3.0 open-source application to download, configure, run, and manage dedicated Minecraft servers on Android with zero root permissions required.

Powered by a native PRoot virtualization engine, a JNI-backed PTY pseudo-terminal, isolated OpenJDK runtimes (Java 8, 17, 21, 25), live telemetry, a built-in Web Remote Admin panel, and a Material Design 3 interface, MineServe turns your phone or tablet into a portable Minecraft server host.

Key Features:

* 100% Rootless Operation: Runs in Android user space using PRoot syscall translation. No root access, Magisk, or unlocked bootloader required.

* Material Design 3 & Material You: Dark and Light themes plus an optional Android 12+ dynamic color toggle, a simplified 2-step server creation wizard, and a unified 6-tab workspace (Console, Performance, Players, Content, World & Map, Management).

* 11 Server & Proxy Engines:
  - PaperMC & PurpurMC: High-performance Bukkit/Spigot/Paper plugin servers.
  - Folia: Regionized multithreading server software for higher player counts.
  - Fabric, NeoForge & Forge: Modded servers from Minecraft 1.1 to 1.21+.
  - Mojang Vanilla: Official Java Edition servers from 1.0 to 1.21+.
  - Bedrock Cross-Play (Geyser + Floodgate): Let Bedrock players join your Java server.
  - Bedrock Dedicated Server (Beta): Official Mojang Bedrock server (native x86_64, qemu-user on ARM64).
  - Velocity & BungeeCord: Link multiple backend servers into one proxy network.

* Isolated Java Runtimes: Automatically downloads OpenJDK 8, 17, 21, and 25 with resumable downloads and local .jar / .tar.gz imports.

* Multi-User Web Remote Admin (:8080): Manage live SSE console logs, browser file editor (drag-and-drop upload and .zip extraction), RBAC team accounts (Owner, Admin, Moderator, Viewer), Audit Log with CSV export, players, backups, plugins/mods, world tools, Squaremap live map, and performance charts.

* Zero-Config Multiplayer Networking:
  - UPnP & NAT-PMP automatic router port forwarding.
  - Built-in bore.pub and Playit.gg public tunnels for 4G/5G and CGNAT.
  - Optional MineServe Cloud add-on (6-digit email code sign-in) for custom *.play.mineserve.app addresses, remote Web Admin relays, and encrypted Cloudflare R2 backups.

* World, Modpack & Backup Tools: Import/export .zip and .mcworld saves, pre-generate spawn chunks, inspect .mca regions, prune uninhabited chunks, search Modrinth, import .mrpack modpacks with automatic client-only mod filtering, and sync backups to local storage, Nextcloud/WebDAV, or Android SAF folders.

* Smart Automation & Safeguards: Idle auto-shutdown, auto-wake on player ping, cron schedules, low-battery and thermal auto-stop, Discord webhooks, Home Screen widget, and Quick Settings tile.

Network Access & External Downloads:
To run dedicated Minecraft servers on Android, MineServe connects to external services:
* Server Software: Official Mojang manifests/binaries, PaperMC, Purpur, Fabric, Forge, NeoForge, and BungeeCord builds.
* Container Environment: Minimal Ubuntu rootfs and Adoptium OpenJDK runtimes (Java 8, 17, 21, 25).
* Tunnel & Cloud Services: bore.pub, Playit.gg, or optional MineServe Cloud (api.mineserve.app & Cloudflare R2) when enabled.
* Community Content: Modrinth REST APIs for plugins, mods, and modpacks, plus Minotar for player avatars.
* Application Updates: Optional version checks against GitHub Releases API (disabled by default; configurable in Settings).
